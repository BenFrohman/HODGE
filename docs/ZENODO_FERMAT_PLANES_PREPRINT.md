## Abstract

Let `F = z0^4 + z1^4 + z2^4 + z3^4 + z4^4 + z5^4` be the Fermat quartic in
six variables over `ℂ`. For `ζ ∈ ℂ` with `ζ^4 = -1`, the linear plane

```text
z0 = ζ z1,   z2 = ζ z3,   z4 = ζ z5
```

lies on `V(F)`. Equivalently, `F` is in the ideal generated by
`z0 - ζ z1`, `z2 - ζ z3`, and `z4 - ζ z5`. The proof is the pair identity

```text
z^4 + w^4 = (z - ζ w) (z^3 + ζ z^2 w + ζ^2 z w^2 + ζ^3 w^3)
```

when `ζ^4 = -1`, applied to the three coordinate pairs. This is ideal
membership. It is not a statement that a Hodge class is algebraic.

## Statement

```lean
theorem fermatQuartic_mem_surfaceZ1 (ζ : ℂ) (hζ : ζ ^ 4 = -1) :
    fermatQuartic ∈ surfaceZ1Ideal ζ
```

The generator sits on the left of each summand, so the membership proof uses
one `Ideal.mul_mem_right` per pair, the same shape as `F_mem_plane`.

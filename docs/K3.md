# K3 surfaces

Author: Benjamin Stanley Frohman. Apache-2.0.

A K3 is dimension 2. Hodge classes on it are type (1,1).
Lefschetz (1,1) supplies the cycles. That is `Hodge/Frontier.lean`:
`k3Surface`, instance `LefschetzOneOne`, theorem `k3Surface_hodge`.

It is not a fourth island of `classical_fourfolds`.
Products `S × S` and Hilbert schemes `S^{[2]}` are fourfolds.
Those are not in this file.

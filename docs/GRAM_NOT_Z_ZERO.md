# Gram bounds, not Hodge on V(F)

Author: Benjamin Stanley Frohman  
Copyright © 2026 Benjamin Stanley Frohman  
License: Apache-2.0

The first two inequalities stand. The third does not.

```
ρ ≥ 3,
 dim im(cl) ≥ 3
```

are proved by the 3×3 Gram matrix of three independent algebraic classes on `V(F)` (the hyperplane square and two independent surfaces in the plane span). They do not force

```
Z = 0.
```

`Z = 0` means

```
Hdg^2(V(F)) ⊂ im(cl),
```

i.e. Hodge holds on this host. That would require either an upper bound on `ρ` matching the algebraic span, or an upper bound on `im(cl)` together with a full list of Hodge classes. Neither is written.

So:

```
ρ ≥ 3,
 dim im(cl) ≥ 3,
 Z uncomputed.
```

Not `Z = 0`. Field 3 empty. Hodge open.

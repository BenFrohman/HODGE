# Chain sextic rank bounds: what Lean proves

Author: Benjamin Stanley Frohman. Apache-2.0. Not a Hodge close.

File: `Hodge/ChainSexticRank.lean`.

## Which quantity

`X = V(F) ⊂ P^5` with `F = x0^5 x3 + x3^6 + x1^5 x4 + x4^6 + x2^5 x5 + x5^6`.
Since commit b27f1a0, `Z_bounds` in `ContainerSeparation.lean` and `HostSplit.lean` has
recorded `2 ≤ ρ_Hdg ≤ 1752`, where `ρ_Hdg(X) = dim_Q Hdg^2(X,Q)` and
`Hdg^2(X,Q) = H^4(X,Q) ∩ H^{2,2}(X)`. In older files, `Z` meant something else: the rational
cokernel (the Hodge classes outside the algebraic span; see `CLAIM_FIX.md`, `GRAM_BOUNDS.md`).
`Z_bounds` itself is only the numeral fact `2 ≤ 1752`, and `Z_status_eq` is a string label.
Both are kept and marked as superseded.

## Proven with no hypotheses

- `jacobianDeg12_finrank_le`: `dim_Q R_12 ≤ 1751` for the Jacobian ring `Q[x]/(∂F)` of this F.
  The ideal is generated by the `pderiv` partials. The proof reduces every degree-12 monomial
  to the 1751 standard monomials.
- `planeSelfIntersection_eq`: `c_2((1+h)^3/(1+6h)) mod h^3 = 21`.
- `gram_det_eq`: `6·21 − 1 = 125`.
- `finrank_rationalPoints_le` and `two_le_finrank_of_gram` are general linear algebra.

## Proven conditional on the explicit geometric bridge

`rho_bounds (D : ChainSexticHodgeBridge H) : 2 ≤ D.rho ∧ D.rho ≤ 1752`.

The bridge hypotheses are not formalized:
- Griffiths residue: `h^{2,2} = 1 + dim R_12`.
- `h^2` and `[Π]` are Hodge classes.
- The cup-product values are `6, 1, 1, c_2(N_{Π/X}) = 21`.

## Not proven

- `dim R_12 = 1751` (only `≤` is proven).
- The exact rank. `STATUS.md` reports 786 from Python; that is not formalized here.
- Any statement about cycle classes or the Hodge conjecture.

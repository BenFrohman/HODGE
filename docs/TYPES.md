# Types of the objects in the ledger

Author: Benjamin Stanley Frohman  
Copyright (c) 2026 Benjamin Stanley Frohman  
License: Apache-2.0

These are different types. Do not rename one as another.

| Name | Type | Value on this host |
|---|---|---|
| `b_4` | Betti number, `Nat` | `2606` |
| `rank H^4_prim` | rank of a lattice, `Nat` | `2605` |
| `L = (h^2)^perp` | primitive Hodge lattice | rank `2605` |
| `Mon(U)` | representation `pi_1(U) -> O(L)` | not computed |
| `O(L_2605)` | orthogonal group of that lattice | ambient of Mon, not a computed subgroup |
| OmegaZero34 | `SL(4,Z)` generated by 3 matrices | rank-4 symplectic/alternating, different program |
| plane-span Gram | `2 x 2` rational bilinear form | `[[6,1],[1,21]]`, det `125` |
| `beta = h^2 - 6[Pi]` | class in `H^4` | `beta^2 = 750` |
| three-class Gram | `3 x 3` rational bilinear form | det `2604` (arithmetic identity) |
| `Aut_diag(X)` | finite subgroup of `PGL(6)` | order `4500` |

`2605` is not a group. `4500` is not monodromy. `2604` is a Gram determinant, not the rank of `O(L)`.

## Visible algebraic span, corrected

Written surfaces on `V(F)`: `h^2`, `[Pi]`, `[Pi_{-1}]`. Gram rank `3`, so

```
rank Lambda_vis >= 3
rank complement <= 2606 - 3 = 2603
```

`Aut_diag(X)` preserves `Pi` and `h`. It does not automatically preserve `Pi_{-1}`: a diagonal scaling `x_i |-> lambda_i x_i` keeps `{x0+x3=x1+x4=x2+x5=0}` only if `lambda_0=lambda_3`, `lambda_1=lambda_4`, `lambda_2=lambda_5`.

OmegaZero34 form `Omega_0` is alternating of type `(1,6)` on `Z^4`. `H^4(X)` is orthogonal of rank `2606`. Those are incompatible types.

# Field 2 is not a miss by itself

Author: Benjamin Stanley Frohman (@BenFrohman).
Copyright (c) 2026 Benjamin Stanley Frohman. Apache-2.0.

A class in H^4 ∩ H^{2,2} is Field-2-shaped. It is a miss only if Field 3 holds:

    γ ∉ im(cl_X).

On X = V(F) the named classes h^2, [Π], [S] = h^2 − [Π] fail Field 3.
F^T is a polynomial, not a class on X. W = u^5 v + v^6 is a germ.
h^{2,2} = 1752 is a complex dimension (docs/HODGE_NUMBERS.md).

Calling Field 2 "a miss" without Field 3 is a category error.
Term B remains uninhabited.
